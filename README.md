# DivPic

Grab any part of the web. Point at a button, a card or a whole page, and DivPic saves it as a crisp PNG or SVG, or drops it into Figma as layers you can actually edit.

**Website:** [divpic.in](https://divpic.in)

## Get it

| Browser | Where |
|---|---|
| Chrome, Arc, Edge, Brave and other Chromium browsers | [Chrome Web Store](https://chromewebstore.google.com/detail/divpic/lpdabdkfnmackfinabbgelafogmahjni) |
| Firefox | [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/divpic/) |
| Safari (macOS 13 or later) | Coming soon to the Mac App Store |

## Report a bug or ask for a feature

This repo is where DivPic's issues live. The extension's code isn't here.

1. [Search the open issues](https://github.com/Ragulsundaram/divpic-public/issues) first. If someone has hit the same thing, add a 👍 or a comment there.
2. Otherwise, [open a new issue](https://github.com/Ragulsundaram/divpic-public/issues/new/choose) and pick a form:
   - **Bug**: something broke or did nothing.
   - **Looks off in Figma**: the page landed in Figma but doesn't match.
   - **Idea**: something DivPic should do.

The page URL, your browser and a screenshot are usually enough to reproduce a problem.

**Don't post anything private.** Issues are public: leave out passwords, tokens and pages behind a login that you can't share.
